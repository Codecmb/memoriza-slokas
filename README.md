# Memoriza Slokas

Aplicación para estudiar y memorizar ślokas.

## 📱 Abrir la aplicación

https://codecmb.github.io/memoriza-slokas/

## 🍎 Instalar en iPhone

1. Abre el enlace de Memoriza Slokas usando **Safari**.
2. Pulsa el botón **Compartir** (el cuadrado con la flecha hacia arriba).
3. Selecciona **Añadir a pantalla de inicio**.
4. Pulsa **Añadir**.
5. Aparecerá el icono de **Memoriza Slokas** en la pantalla del iPhone.
6. Abre la aplicación desde ese icono.

## 🤖 Instalar en Android

1. Abre el enlace de Memoriza Slokas usando **Chrome**.
2. Pulsa el menú **⋮**.
3. Selecciona **Instalar aplicación** o **Añadir a pantalla de inicio**.
4. Confirma la instalación.
5. Abre **Memoriza Slokas** desde el nuevo icono.

## Funciones

- Ślokas para memorización
- Inglés y español
- Palabra por palabra
- Traducciones
- Audio
- Seguimiento del progreso
- Grabaciones personales
- Búsqueda y filtros
- Sistema para marcar versos que necesitan corrección
- Backup y restauración del progreso
